ASTRAVIA Content API v1

Read-only, published content for the website and the future Unreal Engine 5 client. Machine-readable schema: OpenAPI JSON.

Conventions

All responses are JSON. Localized text is returned as {"en": "...", "ar": "..."}. Lists are paginated (?page=, ?page_size= up to 100). Only published content is returned. Hidden content requires an authenticated principal with the core.view_hidden_content permission (token authentication: Authorization: Token <key>). Never ship a privileged token inside a game client.

Endpoints

  • /api/v1/Index of endpoints
  • /api/v1/worlds/Worlds; detail at /api/v1/worlds/<slug>/ includes regions and Unreal level path
  • /api/v1/characters/?world=, ?category=; detail includes biography and relationships
  • /api/v1/quests/Detail includes objectives, prerequisites and rewards
  • /api/v1/dialogues/?world=, ?quest=, ?speaker=, ?category=, ?trigger=; detail by key
  • /api/v1/lore/Memory archive
  • /api/v1/cinematics/Storyboards and Unreal sequence references
  • /api/v1/encounters/Boss encounter data with phases
  • /api/v1/story-arcs/Detail lists chapters; /story-arcs/<arc>/chapters/<chapter>/ returns the branching graph
  • /api/v1/guides//guides/<slug>/lines/?page=home&world=everfrost&lang=ar
  • /api/v1/localization/Interface strings and glossary
  • /api/v1/site-config/Public site configuration
  • POST /api/v1/auth/token/Exchange email and password for a token (rate limited)
  • GET /api/v1/me/, GET /api/v1/me/quests/<slug>/, POST /api/v1/me/quests/<slug>/start/Player endpoints; the server validates every state change
